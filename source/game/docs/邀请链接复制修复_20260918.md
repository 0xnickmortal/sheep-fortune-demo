# 邀请链接复制修复

旧按钮只调用 `navigator.clipboard.writeText`，失败后依赖弹窗外的 toast 提示；原生模态弹窗可能遮挡该提示。部分钱包内置浏览器会拒绝、缺失或挂起剪贴板接口，让玩家误以为按钮没有响应。

本次仅修改邀请链接的复制交互：

- 点击后立即显示“正在复制”；复制成功后按钮显示“已复制 · 再复制一次”，弹窗内显示可粘贴发送的提示。
- 常规接口失败或1.5秒内没有响应时，尝试选择当前弹窗内的链接字段并通过兼容接口复制。不会在模态弹窗外创建无法聚焦的临时输入框。
- 仅在复制接口报告成功时显示已复制；两种接口都失败则显示“重试复制”，保留完整链接并提示长按复制。点击链接可全选。
- 不读取玩家剪贴板内容，不更改邀请码、邀请归属、返佣、白名单或资金权限。
- 新模块同时纳入 Cloudflare 和 GitHub Pages 构建，并更新前端缓存版本。

验证：4项自动测试通过，覆盖完整URL、接口缺失/拒绝/抛错、兼容接口失败以及永不返回的Promise。390×844浏览器通过本地EVM账户登录和实际推荐接口打开邀请页；禁用常规剪贴板后，兼容复制成功且完整URL匹配；模拟两种接口均不可用时，手动复制提示可见、全文选中、按钮可重试。无脚本错误或横向溢出。尚未直接操作真实手机App。

参考：[Clipboard API](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard_API)、[WebKit用户操作权限](https://webkit.org/blog/13862/the-user-activation-api/)。
