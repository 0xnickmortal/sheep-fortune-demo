# 后台资金与盈亏

已上线：Cloudflare 版本 `f2081881-601b-429a-9b22-1998dce7b140`。管理入口：[资金与盈亏](https://dapp.yangnian.xyz/admin/)。使用原项目管理员钱包登录，沿用现有管理员会话与权限校验。

## 页面

- 顶部汇总已入账充值、已完成提现、游戏净盈亏和推荐收益；列出钱包数、当前可用余额、当前冻结额及待处理充提数量。
- 地址总览按钱包独立汇总，支持地址搜索、北京时间日期范围、盈利/亏损/持平/未游戏分类，以及余额、充值、提现、盈亏和最近活动排序。
- 充值记录、提现记录、游戏盈亏和推荐收益分别展示，支持状态或层级筛选。
- 点击地址打开独立档案，展示完整地址、余额和收益汇总，以及该地址的四类分页明细。交易和钱包可跳转 BscScan。
- 每页 25 条；汇总覆盖所选条件的全部记录，不随翻页变化，不受原管理接口 100 条限制。
- 奖池、运营注资、合约持币和用户负债在独立折叠区域展示，读取失败不妨碍查看账户账目。

## 统计口径

所有币额使用 18 位定点整数与 BigInt 汇总，SQL 不使用 SUM/CAST 浮点求和。界面最多展示 4 位小数；省略非零尾数时显示约等号，悬停显示完整金额。接口返回完整精度。

- 游戏净盈亏 = 游戏记录实际净返还 − 下注本金。已含游戏手续费，不重复扣费。
- 综合净收益 = 游戏净盈亏 + 实际推荐收益 − 已完成提现手续费。
- 已入账充值：仅 deposits 中对应正式钱包账户的已确认记录。
- 已完成提现：仅 confirmed 记录的 amount − fee。失败、退回及待处理不算已提现。
- 待处理提现：queued、authorized、submitted 分别显示状态，汇总预计到账额。
- 尚未核验的充值不具备可信金额，显示待核验；失败充值显示未入账。与已入账充值相同的跟踪交易按 asset + tx_hash 去重。
- 日期按每条记录的创建时间筛选，日界线为北京时间 UTC+8。余额、冻结额和历史待入账奖励为当前值。
- 正式代币账户与试玩、其他代币、运营注资分开统计。金元宝不计币本位盈亏。

## API

- `GET /api/admin/finance`：search、wallet、from、to、profit、sort、page、pageSize。
- `GET /api/admin/finance/records`：kind（deposits / withdrawals / rounds / referrals）、search、wallet、from、to、status、page、pageSize。
- 使用原 authorizeAdmin 校验；未登录或普通钱包返回 403；返回 Cache-Control: no-store。
- 不返回提现原始签名交易、密钥或授权凭证。只读，无数据库迁移，不改变结算或资金状态。
