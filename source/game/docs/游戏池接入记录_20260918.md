1. 页面下载「接入记录」，保留部署、绑定和fundPool交易哈希。
2. 核对合约源代码并在Sourcify/BscScan验证。`public/admin/pool/solidity-standard-input.json` 包含完整编译输入；构造参数以接入记录中最终上限为准，不能直接沿用页面默认值。
3. 在wrangler.json设置 `VAULT_ADDRESS` 为新合约，`DEPOSIT_START_BLOCK` 为部署区块，`POOL_SYNC_ENABLED=true`。实际合约必须与部署模板、代币、管理员、签名公钥及burn模式完全一致。
4. 保持 `LIVE_PAYMENTS_ENABLED=false`，部署Worker。
5. 使用服务端OPS_AUTH_KEY调用 `/api/admin/treasury/fund`，提交已确认的fundPool交易哈希，将200万初始资金计入游戏奖池；`/api/admin/pool` 核对用户资金、奖池及链上资产。
