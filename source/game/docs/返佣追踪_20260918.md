# 返佣金额与到账反馈

- 我的账户新增累计返佣卡片，分别显示直推、间推累计金额，支持直接查看明细。
- 邀请好友弹窗展示两级邀请人数、两级累计返佣，以及最近50笔奖励的类型、好友地址、下注金额、返佣金额、时间和游戏余额入账状态。
- 页面处于前台且钱包已登录时约每15秒查询一次，回到页面会立即查询，也可点击“刷新返佣”。
- 当前页面观察到新增返佣时，提示“新返佣 +金额 币，已入游戏余额”，并刷新可用余额。首次读取不将历史收入误报成刚到账。
- 切换钱包和退出登录会清除前一个钱包的展示数据、通知基准，并忽略旧请求的迟到响应。
- 金额使用18位小数的整数运算，保留累计返佣精度。累计返佣是历史获得总额，不等于当前可提现余额，下注、提现不会减少累计值。

返佣仍通过原有后端在每局结算时，从游戏池记入推荐人的可用余额。页面不生成返佣、不修改资金账本、不额外收取手续费。提现完成并经链上确认后，代币才进入用户钱包；页面上的“已入游戏余额”不代表已收到链上转账。

## 验证

- 推荐结算5项、前端追踪4项测试通过，覆盖两级分配、重复请求、各倍率返佣、金额精度、通知去重、失败重试和钱包切换时旧请求隔离。
- 本地EVM三个钱包完成A邀请B、B邀请C并下注的真实应用流程：A累计从125增至175枚，自动显示新增间推50枚，游戏余额同步增加50枚，明细包含新增下注。
- 390像素手机页面和360像素页面无横向溢出；切换B后显示其独立的300枚直推返佣，不继承A的金额或到账提示。
- 本地验证不使用生产钱包、不广播主网交易，不改变线上概率、返佣比例或四钱包开放范围。
