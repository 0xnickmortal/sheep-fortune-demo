统计口径与数据说明

游戏净盈亏 = 每局实际返还 − 下注本金，已包含当局游戏手续费。充值、提现和金元宝不计入游戏盈亏。

综合净收益 = 游戏净盈亏 + 推荐收益 − 已完成提现的手续费。推荐收益按实际入账统计。

累计充值 / 累计提现仅统计已入账充值和已完成提现的实际到账量。待确认充值的金额尚未核验，显示“待核验”，不按 0 计入。

日期范围按记录创建时间筛选，使用北京时间（UTC+8）；余额、历史待入账奖励和冻结额始终为当前值。地址总览和顶部汇总采用相同筛选条件；明细页的状态筛选只影响明细表。

仅统计本游戏正式代币账户；运营注资在下方奖池中单列。数据来自游戏账本，不包含钱包外部交易或链上 Gas 费用。点击任一地址可查看该地址的分类明细。金额最多展示 4 位小数，≈ 表示省略尾数，悬停金额可查看完整数值。
